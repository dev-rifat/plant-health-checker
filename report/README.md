# Pre-Defence Report — AI-Based Smart Farming Support Application

This folder contains the university pre-defence project report for the mobile app
**"Smart Krishi"** (this repository: `plant_health`).

## Files

- **`AI_Based_Smart_Farming_Support_Application_Report.docx`** — the full report, in
  English only (no Bangla script), to avoid the font/glyph-breaking issue seen when a
  Bangla-mixed document is exported to PDF on a system without a Bangla font installed.
- **`assets/`** — the diagrams used in the report (generated, not hand-drawn):
  - `work_procedure.png` — Fig 1, project work procedure flow
  - `block_diagram.png` — Fig 2, system/block architecture
  - `usecase_diagram.png` — Fig 3, use case diagram
  - `activity_diagram.png` — Fig 4, activity diagram
  - `gantt_chart.png` — Fig 5, project timeline

## Why the font was breaking

PDF export tools (and some viewers) only embed the fonts they can find on the machine
that generated the PDF. If a document mixes Bangla script with a Latin font like Times
New Roman, and the exporting tool/font doesn't have Bangla glyphs, those characters
render as empty boxes ("tofu") in the PDF. This report avoids that entirely by staying
in English throughout the document body — the app's real bilingual (Bangla/English) UI
is *described* in English rather than quoted in Bangla script.

## Before you submit / print

1. **Open the `.docx` in Microsoft Word** (not just a PDF viewer — Word is needed to
   update the auto-generated Table of Contents field).
2. **Update the Table of Contents**: right-click anywhere inside the TOC page →
   *Update Field* → *Update entire table*.
3. **Fill in the placeholders** on the cover page, Declaration and Acknowledgement
   (search for anything in `[square brackets]`):
   - Your name(s) and student ID(s)
   - Supervisor's name, designation, department
   - University name and location
   - Submission date / project period
   - Head of Department / Dean names
4. **Insert your screenshots** in Chapter 4 (Section 4.1): each dashed green box
   labelled `[ PASTE SCREENSHOT HERE ]` marks where one of your app screenshots goes
   (Splash screen, Login, Home dashboard, Leaf capture, Analyzing state, Diagnosis
   result). Click the box and insert the picture, or delete the placeholder table and
   paste the image directly.
5. **Export to PDF from Word** (`File → Save As → PDF`, or `File → Export → Create
   PDF/XPS`) rather than any third-party converter — Word embeds the fonts correctly
   so nothing will render broken.

## Regenerating the report

The report and all diagrams are generated by Python scripts (not stored in this
folder, since they're build tools rather than deliverables). If you need to change
wording, tables, or diagrams and regenerate, ask your assistant to re-run the
generation script — it uses `python-docx` for the document and `matplotlib` for the
diagrams, and only ever writes English text into the `.docx` to keep PDF export safe.
